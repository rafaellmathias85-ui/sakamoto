# Odontologia Sakamoto - Website

## Overview
Professional dental clinic website for Odontologia Sakamoto in São Bernardo do Campo, SP, Brazil.

## Visual Style
- **Primary Colors**: Navy blue (HSL 210, 70%, 25-35%) + Gold/Amber (HSL 43, 70%, 50%)
- **Background**: White with subtle muted sections
- **Typography**: DM Sans (body), Plus Jakarta Sans (headings)
- **Design**: Clean, professional, modern medical aesthetic
- **Theme**: Light mode default

## Pages Structure
1. **Home** (/) - Hero, About preview, Services grid (6), Testimonials (4), CTA
2. **Sobre** (/sobre) - History, Values (4), Team (3 dentists)
3. **Serviços** (/servicos) - 9 dental services with descriptions and benefits
4. **Galeria** (/galeria) - Filterable gallery with lightbox
5. **Blog** (/blog) - 6 seeded articles, individual post pages (/blog/[slug])
6. **Contato** (/contato) - Appointment form, contact info, Google Maps embed

## Technical Details
- **Database**: PostgreSQL with Prisma ORM
- **Models**: Appointment, BlogPost, ContactSubmission
- **Email**: Notification on appointment (NOTIF_ID_AGENDAMENTO_DE_CONSULTA)
- **WhatsApp**: Floating button → (11) 4123-7168
- **SEO**: Dynamic sitemap.ts, robots.ts, Open Graph
